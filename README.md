# Cloud Expense Tracker

A simple web application to track, manage, and analyze cloud infrastructure costs.

## Features

- **Dashboard:** View overall cloud spending at a glance.
- **Track Expenses:** Add and manage costs for different cloud services.
- **Categories:** Group expenses by service type (Compute, Database, Storage).
- **Reports:** View monthly expense summaries.

## Built With

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python / Node.js
- **Database:** SQLite / PostgreSQL
